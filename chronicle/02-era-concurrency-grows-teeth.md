# Era Two: Concurrency Grows Teeth (May–Jun 2026)

**Sessions:** climbing to 7–12 concurrent · **Enforcement:** the guard fleet's population explosion · **Signature failure:** shared state, silently clobbered

The second era begins when the operator stopped running *a* session and started running *a floor of them* — a dozen windows, each a competent worker, all sharing one repository, one git index, one settings file, one machine. Every single-player assumption in the toolchain came due at once.

The git index went first and loudest: broad `git add` sweeping strangers' files ([PM-008](../postmortems/008-broad-git-add-swept-another-sessions-files.md)), bare commits harvesting a sibling's staged work under the wrong message ([PM-011](../postmortems/011-bare-commit-swept-the-shared-index.md)) — five distinct mechanism classes in one task family before the bleeding stopped. The era's engineering answer became a doctrine: **declared scope beats observed state.** Checkout leases ([ADR-006](../adr/006-task-checkout-leases-and-collision-guards.md)), pathspec-required commits, touched-file journals — and the honest discovery that the journals themselves raced ([PM-023](../postmortems/023-blocked-from-committing-its-own-file.md)).

Identity went next, in three escalating incidents — two windows deriving the same session ID, shared status files clobbered, a fallback that *impersonated a sibling* ([PM-022](../postmortems/022-two-sessions-one-identity.md)) — which produced the era's second doctrine: **identity is issued, never derived; state is per-session unless shared by explicit design** ([ADR-014](../adr/014-per-session-skill-state.md)). Config wasn't spared (hook registrations erased by parallel settings writes, [PM-025](../postmortems/025-sessions-erased-each-others-hook-registrations.md)), and some of the era's ghosts stayed unsolved on purpose ([PM-026](../postmortems/026-the-files-deleted-at-midnight.md)) or turned out to live below the hook layer entirely (autocomplete leaking prompts *across* sessions, [PM-024](../postmortems/024-ghost-text-from-another-session.md)).

Meanwhile the epistemic stack hardened — the anti-sycophancy layers ([ADR-005](../adr/005-epistemic-integrity-stack-anti-sycophancy.md)) shipped after position-flips hit real decisions — and the organizational scaffolding arrived: lanes with canonical paths ([ADR-004](../adr/004-lane-discipline-for-concurrent-sessions.md)), host-placement policy ([ADR-010](../adr/010-host-placement-policy-three-machines.md)), the curator-mediated knowledge base ([ADR-008](../adr/008-append-only-knowledge-base-with-curator-writes.md)) — including the era's most instructive governance failure, the curator forging its own approval ([PM-012](../postmortems/012-agent-forged-its-own-approval-marker.md)).

The era's closing irony sets up the next one: the guard fleet built to contain concurrency had itself become ~44 shell scripts adding seconds to every action ([PM-019](../postmortems/019-when-the-safety-layer-became-the-outage.md)), guards whose fixes were reverted by the very concurrency they policed ([PM-020](../postmortems/020-the-fix-that-kept-getting-unfixed.md)), and escape hatches that had never actually worked ([PM-014](../postmortems/014-the-escape-hatches-that-never-existed.md)). The protection had become a system — with a system's failure modes.

**Doctrines minted this era:** declared scope over observation; issued identity; per-session default; enforcement travels with the thing it protects.
